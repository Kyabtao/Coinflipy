🎯 A. Side-Pick Games (opposite sides auto-match)

Like the coin toss: Player A picks one side, Player B must pick the opposite side at the same amount. The system auto-matches HEADS vs TAILS (or HIGH vs LOW, LEFT vs RIGHT, etc.). Simplest matching logic — identical to what's already built.

NEW

How to play

🔗 C. Pattern-Pick Games (any two different patterns auto-match)

Both players pick a pattern or sequence. The waiting room auto-matches any two different patterns at the same stake. Flips generate from nonces until one pattern wins.

📊 Matching Logic Summary

How the waiting room auto-matches for each game type.

🌐

Auto-Match Rules by Game Type

Side-pick games (Coin Toss, Over/Under, Tug of War, etc.)

Match condition: same amount + opposite side. A picks HEADS, B must pick TAILS.

Number-pick games (Closest Number, Sum Prediction)

Match condition: same amount + any two different numbers. A picks 42, B picks anything except 42.

Pattern-pick games (Pattern Race, Parlay Duel)

Match condition: same amount + any two different patterns. A picks HTH, B picks anything except HTH.

Range-pick games (Range War, Bullseye)

Match condition: same amount + non-overlapping zones. A claims 0–63, B must claim a zone that doesn't intersect.

No-pick games (Higher Byte)

Match condition: same amount. First two bets at the same stake auto-match; the hash assigns bytes.
